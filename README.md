## 推免流程速览

```mermaid
flowchart LR
  A[核实本校推荐资格与排名] --> B[准备材料并筛选招生单位]
  B --> C[夏令营或预推免考核]
  C --> D[取得本校推免资格]
  D --> E[按当年窗口填报推免服务系统]
  E --> F[确认复试通知并参加考核]
  F --> G[核对待录取信息并在期限内确认]
  G --> H[关注正式备案、公示与毕业资格复核]
```

时间点每年变化；上图说明常见办理顺序，不代表所有单位采用相同批次。
