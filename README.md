# 中国保研（推免）全流程知识手册

**轻保研整理** · 公开版 v1.0.0 · 信息截至 2026 年 10 月

这是一份面向中国大陆本科生的保研知识库，按准备阶段与常见问题组织，覆盖资格评定、择校准备、申请考核、推免系统、录取确认和入学衔接。主要章节可直接在 GitHub 阅读；PDF 保留完整排版、目录、书签、索引和参考文献。

推免政策和院校要求会逐年变化。涉及资格、时间、材料、考核、奖助或录取手续时，请以教育主管部门、所在学校和目标招生单位当年发布的正式文件为准。本手册不承诺资格、入营或录取结果。
