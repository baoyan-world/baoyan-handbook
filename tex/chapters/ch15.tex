\chapter{录取之后：资格复审与入学准备}
\label{ch15}
\ist{入学前后}
\begin{keybox}
这一章处理的是“录取之后”这一段最容易被忽略的时间：从确认待录取到研究生报到，中间隔着将近一年。很多人以为拿到待录取就结束了，其实还有三道关口。第一道是入学前的资格复审，多数学校安排在录取当年6月，审的是学分是否修满、最后一学年有没有不及格、报名至报到期间有没有处分、毕业论文成绩是否达标、能不能拿到毕业证和学位证——任何一项不过，录取资格就可能被取消，这在全国有《普通高等学校学生管理规定》（教育部令第41号）和各校推免办法两套依据。第二道是报到与注册，双证原件、人事档案、政审表、体检都要在这一步到位。第三道是入学后3个月内学校按国家招生规定进行的复查，弄虚作假、徇私舞弊的取消学籍，身心状况不适宜在校学习的可保留入学资格。本章据此分五节：资格复审、休学、更换导师、提前进组、延毕风险。凡属院校特定的部分（复审材料清单、时间点、成绩与论文门槛），都点明学校与年份；凡属经验判断的部分（怎么跟导师开口、提前进组值不值、要不要换导师），归入“经验提示”，与规则条文分开。
\end{keybox}

\section{休学}
\begin{qa}{E0312}{毕业证、学位证没有按时拿到会怎么样？}
结论：后果是录取资格直接无效，几乎没有补救空间。教育部《2027年全国硕士研究生招生工作管理规定》第七十条写明，应届本科毕业生须在录取当年入学前取得国家承认的本科毕业证书，未取得的“其录取资格无效”（\nref{S0442}）。各校表述更直白：中山大学规定推免生“入学前须本科毕业并获得学士学位”，一旦查证不实或不符合要求，取消申请资格、录取资格甚至学籍（\nref{S0167}）；电子科技大学把“录取当年入学前未取得国家承认的本科毕业证”直接列为取消推免录取资格的情形（\nref{S0495}）；哈尔滨工业大学要求报到时交验身份证与学历学位证书原件，报到前未取得毕业证即取消录取资格（\nref{S0066}）。

注意学位证与毕业证是两件事：多所学校同时要求“获得学士学位”（\nref{S0635}、\nref{S0604}），只拿到毕业证不等于过关。

\begin{qa}{E0316}{政审表怎么填？由谁来签字盖章？}
结论：表由你取回、由你所在单位填，但你本人不得经手，必须密封转递。浙江大学能源工程学院2026年通知规定，政审表交本人档案所在高校二级学院如实填报，需填写完整、含所在单位负责人签字及单位公章方为有效，“考生所在单位政审意见”须加盖二级院系党组织公章；并明确政审表应由政审单位寄送、密封且在封口处加盖单位公章，“考生本人严禁接触政审表”（\nref{S0542}）。教育部文件也要求，人事档案审查或政审必须在发放录取通知书之前完成（\nref{S0046}）。中山大学的做法是把“现实表现复审表”放进研招系统由拟录取考生自行下载，再按调档函要求寄回（\nref{S0164}）；哈尔滨工业大学要求现实表现材料由本人档案或工作所在单位的人事、政工部门加盖印章（\nref{S0066}）。

\begin{qa}{E0318}{档案怎么转到研究生学校？自己带过去行不行？}
结论：走“调档函 + 公对公转递”，个人自带通常不被接受。标准流程由招生单位发起：拟录取名单确定后，招生单位向考生所在单位函调人事档案（或档案审查意见）和本人现实表现等材料，函调材料须由本人档案或工作所在单位的人事、政工部门加盖印章（\nref{S0051}、\nref{S0066}）。中山大学把调档函放在研招系统里，由拟录取硕士（含免试生）自行下载，并按调档函要求将材料按时寄回（\nref{S0164}）；浙江大学能源工程学院明确调档一般安排在入学当年5月左右，调档函通过电子邮件发放（\nref{S0542}）；哈尔滨工业大学要求调档工作在10月底前完成（\nref{S0066}）。

注意：推免生同样要调档，不会因为免初试而跳过这一步。

\begin{qa}{E0319}{档案里缺材料（比如入党材料、成绩单）怎么办？}
结论：档案缺件不是“取消资格”的硬条款问题，而是会卡住调档、政审和入学复查的流程问题。国家层面没有“档案缺某材料即取消入学资格”的统一规定；现有的依据是两方面：一是调档与政审要求函调的人事档案（或档案审查意见）须由档案所在单位人事、政工部门加盖印章（\nref{S0051}、\nref{S0066}），材料不齐时对方往往无法出具审查意见；二是入学后学校要做全面复查，西北工业大学明确把“档案复查”列入入学后3个月内的复查内容（\nref{S0506}）。也就是说，缺件的后果是流程被卡住，而不是被直接取消。

\begin{itemize}
  \item 入党材料：回本科院系党组织补齐
  \item 成绩单：教务处重新打印并加盖公章
  \item 登记表类：联系原填表单位补办
\end{itemize}

\begin{qa}{E0323}{预备党员入学后怎么转正？会不会影响？}
结论：跨校本身不影响转正，真正的风险是培养考察材料断档。现有材料中未见针对推免生预备党员转正的专门条款。可依据的关联规则是：《普通高等学校学生管理规定》第十一条规定，学生入学后学校应当在3个月内进行复查，复查内容包括本人及身份证明与录取通知、考生档案等是否一致（\nref{S0040}）；而调档环节要求人事档案与审查意见由档案所在单位盖章出具（\nref{S0051}、\nref{S0066}）。党员材料是人事档案的组成部分，材料不全就可能在转接与复查环节卡住。

  \item 常见做法：由本科党支部密封装入档案，入学后第一时间向新支部报到
  \item 时间点：预备期满前提出转正申请

\begin{qa}{E0326}{入学体检和复试体检有什么区别？}
结论：区别在“谁在什么时候组织、不合格的后果是什么”。教育部规定，考生体检工作由招生单位在考生拟录取后组织进行，各招生单位参照《普通高等学校招生体检工作指导意见》并结合专业实际提出本单位体检要求（\nref{S0442} 第七十二条）。所以“复试体检”通常就是拟录取后的这一次，与录取结果直接挂钩：浙江大学能源工程学院要求拟录取考生自行到校医院或当地二甲以上医院体检，“体检不合格者取消拟录取资格”（\nref{S0542}）。入学后的体检则与学籍绑定：哈尔滨工业大学规定已录取推免生体检在入学报到时进行（\nref{S0066}）；河北大学规定体检在入学报到后进行，体检不合格者经研究生院批准休学，休学期满后仍不合格者取消学籍（\nref{S0604}）。

\begin{qa}{E0338}{保留入学资格、休学怎么申请？需要什么理由？}
结论：这是两条不同路径——保留入学资格发生在入学前，休学发生在取得学籍之后，条件与期限都由学校规定。教育部令第41号（2017年施行）给出全国统一的框架（\nref{S0040}）：

\begin{itemize}
  \item 保留入学资格：新生可以申请，保留期间不具有学籍；期满前应向学校申请入学，经审查合格后办理入学手续，审查不合格的取消入学资格，逾期未办且无不可抗力等正当理由的视为放弃入学资格（第十条）。教育部招生规定同样授权被录取新生可申请保留入学资格，条件期限由招生单位规定，并纳入录取当年招生计划管理（\nref{S0442} 第七十一条）。
  \item 休学：学生申请或学校认为应当休学的，经学校批准可以休学，休学次数和期限由学校规定；休学期间学校保留学籍但不享受在校学生待遇（第二十五、二十八条）。
  \item 应征入伍：新生和在校生应征参加中国人民解放军（含武警），学校应当保留其入学资格或学籍至退役后2年（第二十七条）。
  \item 复学：休学期满前应在学校规定期限内提出复学申请，经学校复查合格方可复学（第二十九条）。
\end{itemize}
\nref{S0040}
\nref{S0442}
\end{qa}

\begin{qa}{E0346}{入学英语分级考试、免修是怎么回事？}
分级是学校按测试或其他依据安排课程层次，免修、免听、免考和学分认定则是不同审批事项，不能混用。《普通高等学校学生管理规定》将考核与成绩评定等具体办法交由学校规定，并不设全国统一的六级或雅思免修分数线。\nref{S0040}

应先找本届研究生院及学院的外语教学通知，核对适用学位类别、成绩有效期、是否必须参加分级考试、申请入口和截止日，再确认获批后是否仍要选课或考试、是否取得学分、成绩如何记载。保存有效成绩证明与申请回执，按系统中的批准结果选课，未经批准不要直接缺课。

例如厦门大学2026级通知说明，学术型硕士英语自2025级、专业学位硕士英语自2026级改由学院安排，研究生公共外语课不再适用该通知中的免修政策；因此往届的“六级够分就免修”经验不能直接沿用。\nref{S0765} 入学前做准备可以，但2027级应等待并核对本届正式文件；不能把英语能力证明与学校审批结果当成同一件事。
\nref{S0040}
\nref{S0765}
\qscope{厦门大学2026级作为年度变化示例；各校、各学院和各届别的外语规则分别核对。}
\end{qa}

\begin{qa}{E0347}{推免生入学后能不能申请硕博连读？}
结论：可以，但走的是校内二次选拔，属院校规定，需要提前规划成绩与导师名额。硕博连读是博士招生的独立方式之一：中国农业大学把博士招生分为直博生、硕博连读、申请考核三种，其中硕博连读是“选拔校内优秀在读硕士生”，由各招生院系依据学校的硕博连读选拔办法组织实施，博士阶段学制3年（\nref{S0160}）。安徽工业大学的硕博连读面向本校全日制非定向在读硕士（含学术学位和专业学位），本科须获学士学位，博士阶段学制3年（\nref{S0161}）。天津医科大学要求面向二、三年级学术学位非定向硕士，须修完全部学位课程、无不及格或补考且课程成绩优良（平均80分以上，公共英语不低于80分）（\nref{S0184}）。

三点差异：申请时点、成绩门槛、是否限同一导师，各校不同。

\nref{S0184}\par\textbf{本版实操补充：} 是否能申请取决于学校的硕博连读制度、学科名额和考核，不会因推免录取身份自动取得博士资格。入学前先查培养方案对申请年级、课程成绩、导师同意、资格考试和退出方式的规定；如果当前主要目标是读硕士，选择导师和项目时也应确认硕士阶段培养安排。硕博连读属于后续培养路径，不能把招生宣传中的“有机会”理解成保证转博。

\begin{qa}{E0321}{农村户口迁到学校后还能迁回农村吗？}
结论：未见全国统一规定，能否迁回取决于生源地户籍政策，且通常不可逆。《普通高等学校学生管理规定》涉及的唯一户口条款是退学情形：“退学学生的档案由学校退回其家庭所在地，户口应当按照国家相关规定迁回原户籍地或者家庭户籍所在地”（\nref{S0040} 第三十一条）。请注意条文说的是“原户籍地”，而不是“恢复农业户口性质”——这是两个概念。除此之外，教育部令第41号没有对在校生户口迁移作出任何规定，也没有承诺迁出后可恢复原户口性质。所以“能不能迁回农村”不是教育系统能回答的问题，要看生源地公安机关的现行户籍政策。
\nref{S0040}
\end{qa}

\begin{qa}{E0320}{户口要不要迁到学校？迁了有什么好处？}
结论：属自愿选择，没有统一规定，迁与不迁各有利弊。《普通高等学校学生管理规定》唯一涉及户口的是退学情形：退学学生的档案由学校退回其家庭所在地，“户口应当按照国家相关规定迁回原户籍地或者家庭户籍所在地”（\nref{S0040} 第三十一条）。除此之外，现行教育部规章并未对在校生户口迁移作出规定，所以“要不要迁”不是教育系统的问题，而是学校、地方户籍政策和个人情况的综合判断。

\begin{itemize}
  \item 迁的好处：在校期间办证、出国、驾照、购房摇号等按当地口径可能更方便（各城市政策不同）
  \item 不迁的好处：保留原户籍地绑定的权益，家里的事不受影响
  \item 关键变量：学校是否强制、迁入后能否落回、落户地址是学校集体户还是街道
\end{itemize}
\nref{S0040}
\end{qa}

2027届推免系统在10月20日结束通知确认窗口后，重点转为核对系统备案、处理资格复核和衔接本科毕业。发生信息异常时应通过招生单位和官方系统渠道处理，保留必要凭证；个人沟通不能替代正式系统记录。 建议按“本人系统状态——招生单位公示——备案结果——本科毕业条件”建立一张核对单：记录招生单位、专业/层次、确认时间和本人可见的备案字段；遇到姓名、专业或学习方式不一致时，把错误字段、页面截图和支持文件一次性提交给研招办，询问是否为展示差异、待更新事项或正式更正，并保存书面答复。不要因系统关闭就尝试自行改动历史申请，也不要把导师口头通知当作备案完成。
\begin{qa}{N0014}{推免服务系统到10月20日关闭后，漏确认的通知还能补吗？}
不能把10月20日之后当作可自动补办的缓冲期。研招网公布的2027届安排是9月21日至10月20日办理志愿及通知确认，10月18日截止填报志愿；系统说明没有承诺关闭后普遍重新开放。若是系统故障或招生单位通知时限与系统窗口冲突，马上通过招生单位研招办和研招网官方渠道提交情况，附考生号、院校专业、通知名称、发生时间、页面截图及报错记录，并询问是否存在个案处理路径。保留工单编号和邮件回执；是否能恢复操作由主管方处理，不能自行认定口头答复等于系统确认，也不要把志愿填报截止日与通知确认截止日混为一谈。（\nref{S0761}）
\qscope{ 2027届推免服务系统安排；其他届次以当届研招网公告为准。}
\end{qa}
\begin{qa}{N0015}{我已确认待录取，但研招网公开名单暂时查不到自己，说明录取失效了吗？}
不必仅凭名单暂未检索到就断定失效。推免服务系统说明把网上报考录取与备案公开都列为系统职能，并明确最终推免生名单、录取名单和推免生学籍注册以系统备案信息为准；公开页面也有规定的查询时限。先登录本人系统确认志愿、招生单位、专业及已接受状态仍可见，保存页面和确认时间，再查看招生单位研究生院/学院的正式公示及更正公告。若姓名、专业或录取类别确有冲突，联系招生单位研招办核对备案数据，提供考生号和截图并要求书面回复；社交平台截图或导师口头承诺不能替代系统记录。（\nref{S0761}）
\qscope{ 2027届系统说明于2026年10月20日复核；名单公开节点依当届公告。}
\end{qa}
\begin{qa}{N0016}{学校拟录取公示和推免系统状态不一致，我应该按哪一个准备入学？}
先把“学校公示”和“系统备案”分别核对，不要自行选择对自己有利的一项。学校公示通常展示拟录取结果，系统承担最终录取信息备案；研招网说明指出最终名单及学籍注册以系统备案信息为准，招生单位负责提供并公开招生信息。发现姓名、专业代码、学习方式或录取类别不一致时，截取两边完整页面、标明查询时间，联系招生单位研究生院研招办核对，必要时抄送学院研究生教务部门；明确问清是否为公示更正、数据同步延迟或录入错误，以及是否需要补交材料。保存书面答复与更正公告，正式材料未更正前不要据此办理不可逆手续。（\nref{S0761}）
\qscope{ 以2027届研招网系统说明为依据，具体更正流程由招生单位办理。}
\end{qa}
\begin{qa}{N0017}{推免系统关闭后发现录取专业、方向或学习方式填错，还能自己改吗？}
不要尝试用新志愿覆盖，也不要认为招生单位邮件可以直接改动备案字段。2027届系统的志愿填报窗口截止于10月18日，通知确认安排持续到10月20日；窗口关闭后能否更正、由谁发起及是否需要重新备案，现有全国页面没有给出统一的个人自助更正机制。立即向招生单位研招办说明准确字段和错误来源，附本人系统截图、通知原文及相关报名材料，请其书面确认备案值和更正方式；如果属于系统技术错误，同时通过研招网官方咨询渠道留单。待收到官方更正或确认前，不要自行按错误字段签署培养、定向或就业材料。（\nref{S0761}）
\qscope{ 2027届系统窗口信息；字段更正属于招生单位个案处理。}
\end{qa}
\begin{qa}{N0018}{导师或学院发来的“已录取”邮件，能代替推免系统中的待录取确认吗？}
不能把邮件、微信或电话承诺当作系统确认。研招网说明要求推免生通过推免服务系统接收并确认招生单位的复试及待录取通知，录取信息还须按规定在系统备案公开。收到邮件后登录本人账号核对招生单位、专业、类别、通知类型和答复期限；若系统没有对应通知，马上联系院系官方联系人核实是不是内部预通知、系统尚未发送或信息有误。要求对方明确下一步和系统操作时限，并保存邮件。若系统已经关闭，应询问招生单位是否能依法依规处理，不自行假定邮件自动产生录取效力。（\nref{S0761}）
\qscope{ 推免系统统一操作要求；个案通知安排以招生单位正式答复为准。}
\end{qa}
\begin{qa}{N0019}{最后一学年出现缓考或补考，已经确认待录取还需要主动报告吗？}
需要尽早向本科推荐高校和接收单位核对，不要等毕业审核才暴露。教育部2027年招生规定要求应届本科毕业生在录取当年入学前取得国家承认的本科毕业证书；学校还会按招生规定复核录取资格。缓考本身不等于不及格，但课程是否按时完成、补考结果如何、是否满足本校推免办法和接收院系复审要求，取决于具体文件。先向教务处确认课程状态、补考日期及成绩入档时间，取得盖章成绩单或正式说明；再书面询问两校是否要求报备、最迟提交日期及复审口径。保存答复并按期补交材料，不要把系统待录取状态理解成免除毕业条件。（\nref{S0762}）
\qscope{ 全国规定与学校复审细则并行；具体课程门槛以推荐高校和接收单位当年文件为准。}
\end{qa}
\begin{qa}{N0020}{确认待录取后发现成绩单或排名证明有录入错误，应该先联系谁？}
先由出具材料的本科教务或推免工作部门核实原始成绩、排名算法和更正权限，再同步告知接收单位研招办。不要自行涂改已盖章文件，也不要只补一份没有说明的“新版本”。建议准备：错误页与原始系统记录、课程/排名计算依据、学校正式更正说明、新版盖章材料；邮件中标出考生号、接收院校专业和已完成的系统确认。请推荐高校确认更正后是否需要重新备案或补报，接收单位确认是否需上传或邮寄新版。更正结论与材料均留档，涉及推免资格变化时要求学校明确后续处理。（\nref{S0761}） （\nref{S0762}）
\qscope{ 具体成绩认定和资格影响由推荐高校核实，接收单位处理录取材料。}
\end{qa}
\begin{qa}{N0021}{推免录取后本科院校更改了我的姓名或身份证信息，怎样避免报到受阻？}
尽快同时联系本科教务/学籍管理部门和录取单位研招办，按招生单位要求办理身份信息更正。教育部学生管理规定要求报到时核验新生本人及身份证明与录取通知、考生档案是否一致，入学后还要在三个月内复查；因此不能只在一个平台改好就认为全链路同步。准备公安机关或相关主管部门出具的变更证明、现用身份证件、原报名信息及录取通知，并询问招生单位是否要在推免系统、学籍注册数据和纸质档案分别更正。所有材料用官方渠道提交，保留受理回执；不要把身份证完整号码发到非官方群聊。（\nref{S0040}） （\nref{S0761}）
\qscope{ 教育部令第41号规定的身份核验要求；具体材料清单由学校确定。}
\end{qa}
\begin{qa}{N0022}{本科毕业证和学士学位证的取得时间不一致，会影响推免入学吗？}
要分别核对两个证书的条件与最晚取得时间，不能把“已毕业”直接等同于两证要求都满足。教育部2027年招生规定明确，应届本科毕业生须在录取当年入学前取得国家承认的本科毕业证书，否则录取资格无效；部分招生单位的推免细则还要求取得学士学位证书，或在特定日期前完成学位审核。现在就向本科教务部门确认毕业审核、学位评定和制证时间，向接收单位研招办核对该专业当年书面要求；若学位授予存在延迟风险，取得正式说明并尽早提交，不要等到报到日才提出。（\nref{S0762}）
\qscope{ 本科毕业证要求适用全国规定；学位证的附加门槛以招生单位当年细则为准。}
\end{qa}
\begin{qa}{N0023}{接受待录取后，什么情况要主动留存沟通和系统证据？}
遇到时间冲突、信息不一致、故障或材料更正时应留存；普通浏览页面则无需过度收集他人信息。建议保留本人系统通知详情、操作成功页、院校正式公示及更正公告、往来邮件、官方咨询工单编号和提交材料回执，并记录页面地址与截图时间。截图应覆盖关键字段和页面来源，遮盖身份证号、手机号、其他考生个人信息；原始文件保存在本人受控设备，避免发到公开社群。研招网说明要求最终录取信息以系统备案为准，也提供招生单位及省级教育行政部门/考试机构的咨询申诉路径，清晰证据能帮助对方定位问题，但不意味着必然获准补办。（\nref{S0761}）
\qscope{ 通用办事留痕建议；证据采纳和处理结论由主管单位决定。}
\end{qa}

\section{提前修课与联合培养履约}
\begin{qa}{E2026102204}{大四提前修过研究生课程，入学后会自动认定学分吗？}
不会因为旁听或拿到成绩就自动认定。先确认自己是否在提前修课的适用对象内、课程是否经正式选课及考核、是否列入入学后的培养计划。南京邮电大学面向2026级本校推免生的通知要求，合格课程原则上须为其2026级个人培养计划所列课程，且提醒新培养方案可能调整；不能把该政策外推给外校推免生。厦门大学2026级通知则要求本校本科期间提前修读课程的学生向学院申请成绩与学分认定。建议保存课程号、学分、教学大纲、正式成绩单与选课记录，入学后在本校认定期限内申请并检查系统结果。老师口头同意、提前进组或完成课程都不能替代正式录取、注册与学分审批。
\nref{S0765}
\nref{S0766}
\qscope{两校2026级历史通知对照；2027级及外校课程必须重新核对适用对象与认定条件。}
\end{qa}

\begin{qa}{E2026102205}{提前修课后培养方案改了，原课程不再必修，能直接抵新课吗？}
不能只按课程名称相近自行抵扣。南京邮电大学2026级提前修课通知已提示培养方案可能调整，并把计入学分与个人培养计划衔接。拿新旧方案、课程号、学时学分、课程大纲和考核成绩，请学院确认属于课程替代、选修学分认定，还是必须补修；同时询问是否需要导师审批和研究生院备案。还在选课期内的，应先查本届退选期限与办理入口，避免直接旷课或缺考；已修完的，保留成绩并申请书面认定，不自行删除记录。按“原课程—拟替代课程—审批人—系统结果”记录处理进度，未获批准前不要假设已满足毕业学分。该通知的2025年选退课日期已过，不能作为当前届别的办理日历。
\nref{S0766}
\qscope{历史通知支持培养方案衔接原则；替代、退选和补修具体规则由所在院校当届规定。}
\end{qa}

\begin{qa}{E2026102206}{课程批准免修后，会按原成绩计入研究生绩点吗？}
要看学校对成绩与学分的具体记载规则，“免修”本身不能推出绩点算法。厦门大学2026级通知允许本校本科阶段提前修读的研究生课程申请认定，同时明确免修课程不计入绩点，专业课按免修性质录入；这与把原始高分直接带入绩点并非一回事。申请前请学院分别确认四项：是否取得学分、成绩如何显示、是否计入平均分或绩点、学业奖学金等评选另用什么算法。获批后下载研究生成绩单，核对课程号、学分与成绩标记，再按评奖通知计算，不自行把“免修”换成满分。后续转博或更换培养方案时，也要重新核验适用规则；本科成绩单上的分数不能自动证明研究生绩点。
\nref{S0765}
\qscope{厦门大学2026级专业课免修示例；不能概括为全国统一绩点或评奖规则。}
\end{qa}

\begin{qa}{E2026102207}{联合培养做出的代码、专利和论文，署名与知识产权应在什么时候谈清？}
应在进入项目、接触数据和提交成果之前形成书面约定。暨南大学生命科学技术学院2019年办法及协议样例要求明确知识产权、保密、待遇和安全等事项；样例将成果归属与论文署名分别处理，署名还须满足学生学位授予要求，不能从“我写的代码”直接推出个人可自由发布。请校内外导师与学院明确成果类型、权利归属、作者贡献与署名原则、单位署名顺序、专利申请安排及开源审批。把学位论文所需材料、离开项目后的数据和代码使用权限一并问清，保存经授权的协议版本。若协议空白或与毕业要求冲突，先交学院协调，别只凭口头承诺进入长期项目，也不要把企业保密材料上传公开代码仓库。

\begin{qa}{E2026102208}{联合培养企业要求论文先过保密审核，会影响开题和答辩安排吗？}
可能影响，需在选题时提前对齐。上海海事大学公开保密承诺书样例要求，使用基地业务素材须先取得书面同意，相关论文内容由企业导师检查是否涉及保密资料，需修改时可能推迟答辩；这一条不能概括成所有学校通用期限。开始项目时请校内导师和学院确认可用于学位论文的数据、保密审核责任人、送审所需时间、公开成果范围，以及无法按时获批时的替代选题或延期办理路径。把校历中的开题、中期和论文送审节点与企业审核节点逐项对齐，提前提交可审查版本并留回执。企业允许公开不等于已满足学校学位要求；涉及涉密论文时须走学校专门程序，不要自行删除敏感词后就对外发表。
